프로젝트에 이미 있는 이미지를 PhotoCraft(포토샵과 비슷한 이미지 편집 엔진)의 명령으로 편집하고 같은 파일에 덮어쓴다. 사용자가 파일 탭의 "편집" 창에서 쓰는 것과 같은 엔진이다.

학생이 이미 있는 이미지를 고쳐 달라고 할 때 쓴다: 크기 변경·자르기·회전, 밝기·대비·곡선·색조/채도 같은 보정, 반전·흑백, 흐림·선명하게 같은 필터, 글자 넣기, 붓으로 그리기, 그라디언트, 레이어 추가 등. 새 그림을 처음부터 그리는 일은 generate_image 를 쓴다.

## 쓰는 법

1. 명령 ID 와 파라미터를 모르면 먼저 `image_commands` 로 찾는다(예: filter "resize", "curves", "text"). 추측한 ID 는 실패한다.
2. `steps` 에 명령을 순서대로 담아 한 번에 보낸다. 각 단계는 `{ "command": "<ID>", "params": { … } }` 이다.
3. 한 단계라도 실패하면 아무것도 저장하지 않고 원본을 그대로 둔다. 결과의 오류를 보고 고친 뒤 처음부터 전체 목록을 다시 보낸다.

예:
- 반전: `[{ "command": "image.adjustments.invert" }]`
- 흐림: `[{ "command": "filter.blur.gaussianBlur", "params": { "radius": 3 } }]`
- 크기: `[{ "command": "image.imageSize", "params": { "width": 512, "height": 512, "resample": "bicubic" } }]`
- 붓질: `[{ "command": "paint.stroke", "params": { "points": [[100,100],[400,300]], "size": 20, "color": "#ff0000" } }]`

## 주의

- 결과 이미지는 볼 수 없다. 좌표·크기·색은 수치로만 정하고, 결과에 나온 이미지 크기를 참고한다. 원하는 결과가 맞는지는 학생에게 확인을 부탁한다.
- PSD 가 아닌 파일(PNG·JPEG·WebP 등)은 저장할 때 레이어가 하나로 합쳐진다. 레이어를 남겨야 하면 학생에게 PSD 로 저장할지 먼저 묻는다.
- 편집하는 동안 그 이미지의 편집 창은 보기만 되고, 끝나면 새 내용으로 갱신된다.
- 같은 이미지를 동시에 두 번 편집할 수 없다. "이미 편집 중"이 나오면 끝난 뒤 다시 부른다.
