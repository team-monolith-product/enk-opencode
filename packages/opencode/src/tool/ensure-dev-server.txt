결과물 미리보기용 dev 서버가 지정 포트에서 LISTEN 중인지 확인하고, 없으면 백그라운드로 띄운다.

매 응답 턴마다 이 도구를 한 번 호출하면 idempotent 하게 미리보기 환경이 보장된다. 직접 `nohup ... &` / `sleep N` / `/dev/tcp` 로 launch 명령을 짜지 말고 항상 이 도구를 쓴다.

## 동작

- 이미 LISTEN 중이면 서버를 재시작하지 않고 `already_running` 으로 즉시 반환.
- LISTEN 중이 아니면 detached 백그라운드 프로세스로 launch 한 뒤 포트가 LISTEN 될 때까지만 폴링. `sleep 8` 같은 고정 대기 없음.
- LISTEN 확인 후 포트가 루프백(127.0.0.1) 밖에서도 열려 있는지 한 번 더 확인한다. 루프백에만 바인드돼 있으면 `loopback_only`.
- stdio 는 도구가 내부에서 ignore 처리하므로 학생 응답이 hang 되지 않는다. 학생이 "서버 로그 보여줘" 라고 명시적으로 요청할 때만 별도로 로그 파일에 띄워 `tail` 로 확인한다.

## 인자

- `cmd`: 실제 dev 서버 명령. 아래 예시 참고. `nohup` · `&` · `>` 같은 백그라운드 처리는 도구가 알아서 한다.
- `cwd`: 프로젝트 디렉토리. 생략하면 현재 instance 디렉토리.
- `port`: 생략하면 3000. OpenCode 환경에서는 3000 고정.
- `ready_timeout_ms`: LISTEN 시작까지의 최대 대기 시간. 생략하면 15000.

## 명령 예시 (`cmd` 인자 값)

- 정적 HTML/CSS/JS (환경변수 불필요): `npx --yes serve -l 3000 .`
- Vite / CRA: `npm run dev -- --host 0.0.0.0 --port 3000`
- Next.js: `npm run dev -- --hostname 0.0.0.0 --port 3000`

`browser-sync` 는 사용하지 않는다. 미리보기 리로드는 앱이 파일 변경을 감지해 자체 처리한다.

## `.env` 변경 반영

학생이 UI로 API 키 등을 `.env`에 저장하면, 미리보기가 그 값을 바로 쓰길 기대한다. `cmd`를 고를 때 가능하면 `.env` 변경을 감지해 다시 읽거나 재기동하는 서버를 쓴다.

- 앱이 환경변수를 쓰면 Vite / Next 등 `npm run dev` 계열을 우선한다. 이런 서버는 `.env` 변경 시 재기동·재로드하는 경우가 많다.
- 환경변수가 필요 없는 순수 정적 페이지만 `serve` 로 띄운다.
- `.env` 를 한 번만 읽고 이후 무시하는 고정 서버·일회성 정적 서빙은, 시크릿이 필요한 앱에서는 피한다.
- 별도 래퍼·감시 스크립트를 새로 짜지 말고, 프레임워크가 제공하는 기본 `dev` 명령을 쓴다.

## 반환

JSON 문자열. `status` 필드:

- `already_running`: 호출 시점에 이미 LISTEN 중이었음. `url` · `port` · `ms` 가 함께 온다.
- `started`: 새로 띄워 LISTEN 까지 확인됨. `url` · `port` · `ms` 가 함께 온다.
- `failed`: 띄우는 데 실패. `reason` 을 읽고 명령어를 고친 뒤 다시 호출한다.
- `loopback_only`: LISTEN 은 됐지만 127.0.0.1 에만 바인드됨. **미리보기가 안 뜨는 상태이므로 성공으로 보고하지 말 것.** `url` 이 오지 않는다.

`loopback_only` 는 `--host 0.0.0.0`(Next.js 는 `--hostname 0.0.0.0`)을 빠뜨렸을 때 나온다. 미리보기는 외부 프록시가 `pod:포트` 로 라우팅하므로 루프백 전용 서버에는 닿지 못한다. 복구 순서:

1. 포트를 잡고 있는 프로세스를 종료한다: `kill $(lsof -t -i:3000)`. 재바인딩하려면 반드시 먼저 죽여야 하며, 안 죽이면 다음 호출도 계속 `loopback_only` 다.
2. 호스트 바인딩을 붙인 `cmd` 로 이 도구를 다시 호출한다.

성공(`already_running` · `started`) 시 `url` 을 학생에게 그대로 안내한다.
