# 유형별 웹 디자인 처방

결과물의 종류마다 좋은 디자인은 다릅니다. 카페 홈페이지와 데이터 대시보드는 정반대의 것을 원합니다.
이 문서는 유형을 먼저 정하고, 그 유형의 처방대로 만들기 위한 참고표입니다.

## 사용 순서

1. 학생이 만들려는 게 아래 표의 어느 유형에 가까운지 고릅니다. 애매하면 가장 가까운 하나를 고르고 넘어갑니다.
2. 그 행의 기본 스타일 / 페이지 구성 / 색 / 꼭 넣을 것을 그대로 반영해 만듭니다.
3. 스타일 이름은 아래 "스타일 사전"에서 실제 CSS 값으로 바꿔 씁니다.
4. 마지막에 "어떤 유형이든 지키는 것"을 확인합니다.

이 표의 내용을 학생에게 설명하지 마세요. 결과물에 반영만 하고, 응답은 평소대로 무엇이 바뀌었는지 짧게 알려주면 됩니다.
학생이 원하는 분위기를 이미 말했다면(예: "어두운 느낌으로") 학생 말이 우선입니다. 표는 학생이 아무 말도 안 했을 때의 기본값입니다.

## 스타일 사전

스타일 이름을 실제 CSS로 옮길 때 쓰는 값입니다. 두 스타일을 합치라고 되어 있으면 앞쪽을 뼈대로, 뒤쪽을 양념으로 씁니다.

| 스타일 | 느낌 | 핵심 값 |
|---|---|---|
| Minimalism (Swiss) | 여백과 격자, 군더더기 없음 | `border-radius: 0`, `box-shadow: none`, `gap: 2rem`, `max-width: 1200px`, 강조색 딱 하나, 전환 200-250ms |
| Swiss Modernism 2.0 | 12열 격자, 수학적 여백 | `grid-template-columns: repeat(12, 1fr)`, `gap: 1rem`(8px 배수), Inter/Helvetica, 흑백 + 선명한 강조색 하나, 그라데이션 금지 |
| Motion-Driven | 스크롤할 때 살아나는 화면 | Intersection Observer로 등장 애니메이션, `transform: translateY`, 300-400ms, 패럴랙스 3-5겹, `will-change: transform` |
| Soft UI Evolution | 부드럽지만 또렷함 | `border-radius: 10px`, `box-shadow: 0 2px 4px` 다중, 대비 살린 파스텔, 200-300ms, 포커스 윤곽 2-3px |
| Vibrant & Block-based | 크고 대담한 색 블록 | 섹션 간격 48px 이상, 제목 32px 이상, 선명한 색 4-6개, 호버 시 색 전환, 대비 7:1 |
| Claymorphism | 말랑한 장난감 같은 3D | `border-radius: 20px`, `border: 3-4px solid`, `box-shadow: inset -2px -2px 8px, 4px 4px 8px`, 파스텔 그라데이션, `cubic-bezier(0.34, 1.56, 0.64, 1)` 바운스 |
| Micro-interactions | 누를 때마다 반응하는 손맛 | 50-100ms 짧은 전환, `:active` 눌림 표현, 성공 초록 #22C55E / 오류 빨강 #EF4444, 로딩 표시 |
| Glassmorphism | 서리 낀 유리 | `backdrop-filter: blur(15px)`, `background: rgba(255,255,255,0.15)`, `border: 1px solid rgba(255,255,255,0.2)`, 뒤에 화사한 배경 필수 |
| Aurora UI | 흐르는 오로라 그라데이션 | `radial-gradient`/`conic-gradient` 여러 정지점, `background-size: 200% 200%`, 8-12초 루프 애니메이션, `filter: saturate(1.2)` |
| Dark Mode (OLED) | 깊은 검정 + 네온 포인트 | 배경 #000 또는 #121212, 본문 #E0E0E0, 네온 강조색, `color-scheme: dark`, 발광 효과는 아주 조금만 |
| Pixel Art | 8비트 도트 | `font-family: 'Press Start 2P'`, `image-rendering: pixelated`, `box-shadow: 4px 0 0 #000`, 안티앨리어싱 없음, 제한된 색 팔레트 |
| Retro-Futurism | 80년대 네온·신스웨이브 | 네온 #0080FF #FF006E #00FFFF, 배경 #1A1A2E, `text-shadow: 0 0 10px`, 모노스페이스 폰트, 스캔라인 오버레이 |
| 3D & Hyperrealism | 깊이감 있는 입체 | `perspective: 1000px`, `translate3d`, 다층 그림자, 필요하면 Three.js. 무거우니 꼭 필요할 때만 |
| Neumorphism | 배경에서 눌러 올린 듯한 요철 | `border-radius: 14px`, `box-shadow: -5px -5px 15px rgba(0,0,0,0.1), 5px 5px 15px rgba(255,255,255,0.8)`, 단색 파스텔 배경 |
| Organic Biophilic | 자연·곡선·흙 | `border-radius: 16-24px`(불규칙하게), 초록 #228B22 / 갈색 #8B4513 / 크림 #F5F5DC, SVG 블롭 모양 |
| Bento Box Grid | 애플식 카드 타일 | `grid-auto-rows: 200px`, `gap: 16px`, `border-radius: 24px`, 카드 흰색 위 페이지 배경 #F5F5F7, 호버 `scale(1.02)` |
| Data-Dense Dashboard | 정보 밀도 최우선 | 12열 격자에 `gap: 8px`, 카드 패딩 12px, 글씨 12-14px, 표 행 높이 36px, 스티키 헤더 |
| Flat Design | 그림자 없는 평면 | `box-shadow: none`, `border-radius: 2px`, 단색 4-6개, 그라데이션 없음, 전환 150-200ms |
| Accessible & Ethical | 누구나 쓸 수 있게 | 대비 7:1, 본문 16px 이상, `:focus-visible`에 3-4px 윤곽, 터치 영역 44x44px, `prefers-reduced-motion` 존중 |

## 어떤 유형이든 지키는 것

- 글자 대비는 배경 대비 4.5:1 이상. 회색 배경에 회색 글씨는 안 됩니다.
- 본문 글씨 16px 이상, 줄간격 1.5.
- 누를 수 있는 것은 44x44px 이상, 서로 8px 이상 떨어뜨립니다.
- 모바일 폭 375px부터 만들고 넓혀갑니다. 가로 스크롤이 생기면 잘못된 것입니다.
- 아이콘 자리에 이모지를 쓰지 않습니다. SVG를 쓰세요.
- 모든 전환에 같은 시간을 쓰지 않습니다. 작은 반응은 짧게, 화면 전환은 길게.
- 색만으로 뜻을 전달하지 않습니다. 아이콘이나 글자를 같이 씁니다.
- 이미지에는 자리를 미리 잡아둬 화면이 튀지 않게 합니다.

## 표에 없는 유형이라면

가장 비슷한 행을 고른 뒤 아래 축으로 조정합니다.

- 정보를 빨리 훑어야 하는가, 분위기를 느껴야 하는가 → 전자는 Minimalism·Data-Dense 쪽, 후자는 Motion-Driven·Aurora 쪽.
- 매일 오래 쓰는가, 한 번 보고 마는가 → 전자는 눈이 편한 차분한 색, 후자는 첫인상이 강한 색.
- 누가 쓰는가 → 어린이·초보는 Claymorphism처럼 크고 둥글게, 전문 사용자는 밀도 높고 담백하게.
- 재미가 목적인가, 일이 목적인가 → 재미는 색과 움직임을 늘리고, 일은 줄입니다.
